# 🤝 Guía de Contribución

¡Gracias por tu interés en contribuir a **RubiVault**! Este documento explica cómo puedes ayudar a mejorar el proyecto a través del triaje y la gestión de issues.

---

## 📋 ¿Cómo puedes contribuir?

### 🔍 Triaje de issues

Una de las formas más valiosas de contribuir es ayudando a triagear issues existentes:

- **Reproducir bugs**: Intenta reproducir los bugs reportados y confirma (o desmiente) si son reproducibles.
- **Añadir información**: Si puedes agregar información adicional a un issue, hazlo con un comentario.
- **Identificar duplicados**: Si encuentras un issue duplicado, señálalo con un comentario y la etiqueta `duplicate`.
- **Votar issues**: Usa las reacciones 👍 en los issues que consideras importantes para mostrar tu apoyo.

### 📝 Reportar bugs

1. **Busca primero**: Verifica que no exista ya un issue similar en el [listado de issues](../../issues).
2. **Usa la plantilla**: Al crear un issue, selecciona la plantilla **Bug Report** y completa todos los campos.
3. **Sé específico**: Incluye pasos detallados para reproducir el bug, el comportamiento esperado y el actual.
4. **Adjunta evidencia**: Las capturas de pantalla, videos y logs son muy útiles.

### ✨ Solicitar funcionalidades

1. **Busca primero**: Verifica que no exista ya una solicitud similar.
2. **Usa la plantilla**: Selecciona la plantilla **Feature Request** y describe tu idea claramente.
3. **Explica el caso de uso**: Incluye por qué la funcionalidad sería útil y cómo la usarías.

---

## 📏 Estándares de calidad para issues

Para que un issue sea procesado rápidamente, debe:

- ✅ Tener un título descriptivo y conciso
- ✅ Usar la plantilla correspondiente con todos los campos completos
- ✅ Estar escrito en español o inglés
- ✅ No contener información sensible (contraseñas, tokens, datos personales)
- ✅ Incluir evidencia reproducible (para bugs)

---

## 🏷️ Uso de etiquetas

El equipo de mantenimiento es responsable de asignar etiquetas. Sin embargo, puedes sugerir etiquetas en tus comentarios.

| Etiqueta | Significado |
|----------|-------------|
| `bug` | Error confirmado |
| `enhancement` | Nueva funcionalidad aprobada |
| `question` | Requiere respuesta o aclaración |
| `duplicate` | Issue duplicado |
| `wontfix` | No se implementará |
| `good first issue` | Recomendado para nuevos colaboradores |
| `help wanted` | Se solicita ayuda de la comunidad |
| `priority: high` | Urgente |
| `priority: medium` | Normal |
| `priority: low` | Puede esperar |
