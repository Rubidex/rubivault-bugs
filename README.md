# 🐛 RubiVault — Issue Tracker

> Repositorio centralizado para reportar bugs, solicitar funcionalidades y dar seguimiento a mejoras del proyecto **RubiVault**.

---

## 📋 ¿Qué es este repositorio?

Este repositorio es el sistema oficial de seguimiento de issues para **RubiVault**. Aquí puedes:

- 🐛 **Reportar bugs** que hayas encontrado
- ✨ **Solicitar nuevas funcionalidades**
- 💬 **Hacer preguntas** sobre el proyecto
- 🔒 **Reportar vulnerabilidades de seguridad**

> **Nota:** Este repositorio es exclusivamente para el seguimiento de issues. El código fuente principal de RubiVault se encuentra en su repositorio correspondiente.

---

## 🚀 ¿Cómo reportar un issue?

### 1. Busca issues existentes primero

Antes de abrir un nuevo issue, por favor busca en los [issues existentes](../../issues) para evitar duplicados.

### 2. Elige la plantilla adecuada

Al abrir un nuevo issue, selecciona la plantilla que mejor corresponda:

| Plantilla | Cuándo usarla |
|-----------|---------------|
| 🐛 **Bug Report** | Algo no funciona como debería |
| ✨ **Feature Request** | Quieres proponer una nueva funcionalidad |
| 💬 **Pregunta / Question** | Tienes una duda sobre el proyecto |

### 3. Completa la plantilla con detalle

Cuanta más información proporciones, más rápido podremos ayudarte. Incluye:
- Pasos exactos para reproducir el problema
- Comportamiento esperado vs. comportamiento actual
- Capturas de pantalla si aplica
- Versión del sistema operativo y navegador

---

## 🏷️ Sistema de etiquetas (Labels)

| Etiqueta | Descripción |
|----------|-------------|
| `bug` | Algo no funciona correctamente |
| `enhancement` | Nueva funcionalidad o mejora solicitada |
| `question` | Se necesita más información o aclaración |
| `documentation` | Mejoras o correcciones en la documentación |
| `duplicate` | El issue ya fue reportado anteriormente |
| `good first issue` | Ideal para nuevos colaboradores |
| `help wanted` | Se necesita ayuda extra |
| `invalid` | El issue no aplica o no es reproducible |
| `wontfix` | No se implementará en este momento |
| `priority: high` | Debe resolverse urgentemente |
| `priority: medium` | Prioridad normal |
| `priority: low` | Puede esperar |
